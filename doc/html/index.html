ScholarMind 设计图表（可交互）

按 2026-11-16 两轮改版口径绘制：用户端 6 页（首页检索 / 结果页 / 详情 / 三栏阅读 / 问答 / 书房）+ 管理端 6 页；文献由管理员统一上传、上传即发布，四类文献类别与中图法 8 个学科门类；首页收敛为单一搜索框 + 独立层级 RAG 大按钮，阅读页中栏内嵌原文、AI 摘要分节渲染。四张图均为独立 HTML，可缩放、拖拽、切换视图与导出。

01 · ARCHITECTURE
新架构总览

用户端 / 管理端 SPA、Spring Boot API、检索编排（7 维度筛选 + BM25 + 向量 + RRF）、AI 能力（摘要结构化 JSON + 前端分节渲染），以及 MySQL（15 张表）/ Milvus（185 分块）/ RustFS（/download 与 /preview 两套预签名）/ 火山方舟 Ark。阅读页节点标注「内嵌原文 + AI 摘要分节」。
02 · WORKFLOW
新业务流程

用户端 6 环节 + 管理端 6 环节：首页检索（单一搜索框 + RAG 大按钮）→ 结果页筛选 → 详情 → 三栏 HTML 阅读（目录 + 内嵌原文 + 问答笔记）→ 书房；管理端上传即发布（9 字段 + 被引 + 参考文献 + 可选原文 → 自动建索引与摘要）。
03 · ROADMAP
两轮改版交付全景

2026-11-16 两轮需求全部交付：第一轮迁移 13 加被引与参考文献两列、收藏夹表与 8 个学科门类，种子 14 补 14 篇文献与 28 分块，检索 7 维度与年度区间；第二轮新增原文预览接口、摘要分节渲染、阅读页内嵌原文、首页收敛为单一搜索框；回归 66 例全绿。
