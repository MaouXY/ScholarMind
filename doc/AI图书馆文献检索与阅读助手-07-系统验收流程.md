## 八、常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 后端启动报 `Port 8992 was already in use` | 已有实例在跑 | `Get-NetTCPConnection -LocalPort 8992 -State Listen` 找到 PID 后 `Stop-Process`，或先停止旧实例 |
| 前端启动报端口占用 | 5173 被占 | 关闭占用进程，或修改 `ScholarMindWeb/vite.config.ts` 的 `server.port` |
| 文献上传失败 / 下载提示未绑定文件 | RustFS 未启动或 bucket 不存在 | 启动 RustFS，确认 bucket `scholar-mind` 存在 |
| 「向量检索未就绪」 | Milvus 未启动或分块未写入向量 | 启动 Milvus 后执行 `/admin/rag/literature-vectors/rebuild` |
| Milvus 报 `Incorrect dimension for field 'vector'` | `app.agent.rag.milvus.dimension` 与 embedding 模型实际维度不一致 | 该模型为 **2560**；服务已在写入时自动删表重建，如仍失败请核对配置 |
| AI 摘要/问答提示服务不可用 | Ark Key 或模型名不可用 | 检查 `application.yaml` 的 `app.ai.ark.*`；失败记录可在「AI 调用日志」查看 |
| 页面列表为空 / 图表全 0 | 未执行演示数据脚本 | 执行 `sql/00~08` 与 `scripts/seed-demo-files.ps1` |
| 中文数据插入报 `Incorrect string value` | mysql 客户端字符集非 utf8mb4 | 执行 SQL 时加 `--default-character-set=utf8mb4` |
