本文档用于毕业设计验收 / 答辩现场演示：按顺序执行即可完成一轮完整验收。每条用例含**操作步骤**、
**预期结果**与**实测记录（留空待填）**三列，验收时逐条勾选即可。

> 版本对应 2026-10-31《完善需求（改）》+ 2026-11-15 管理员上传改版：删除教师端，只保留**用户端**与**管理端**；

> 2026-11-15 客户改版：**文献改由管理员统一上传、上传即发布、用户端只读**，删除可见性与审核流程；

## 一、验收范围与角色

| 角色 | 覆盖能力 |
| --- | --- |
| 用户 STUDENT | 首页**一个检索栏**（左侧「检索方式」切文献检索 / 智能问答，第二段随方式切维度或召回方式）、结果页筛选（学科 / 年度 / 文献类别 / 七个检索维度）、文献详情、AI 摘要分节渲染、三栏 HTML 阅读（目录跳转 + 内嵌原文 + 进度自动保存）、笔记、收藏与收藏夹、引用管理（三种格式）、下载原文、独立智能问答（**只读：无上传/编辑/审核入口**） |
| 管理员 ADMIN | **文献上传（9 题录字段 + 被引次数 + 参考文献 + 可选原文，上传即发布）**、编辑题录/更换原文、**文献库管理与删除（级联清理）**、用户管理、分类管理、RAG 知识库维护、文献向量重建、AI 调用日志、统计看板、热门关键词、运营分析报告、数据大屏 |

> 教师端已下线：`TEACHER` 仅作为历史数据兼容值存在，教师账号登录返回 `9004`，前端登录页只提供「用户 / 管理员」两种身份。

## 八、常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 后端启动报 `Port 8992 was already in use` | 已有实例在跑 | `Get-NetTCPConnection -LocalPort 8992 -State Listen` 找到 PID 后 `Stop-Process`，或先停止旧实例 |
| 前端启动报端口占用 | 5173 被占 | 关闭占用进程，或修改 `ScholarMindWeb/vite.config.ts` 的 `server.port` |
| 文献上传失败 / 下载提示未绑定文件 | RustFS 未启动或 bucket 不存在 | 启动 RustFS，确认 bucket `scholar-mind` 存在 |
| 「向量检索未就绪」 | Milvus 未启动或分块未写入向量 | 启动 Milvus 后执行 `/admin/rag/literature-vectors/rebuild` |
| Milvus 报 `Incorrect dimension for field 'vector'` | `app.agent.rag.milvus.dimension` 与 embedding 模型实际维度不一致 | 该模型为 **2560**；服务已在写入时自动删表重建，如仍失败请核对配置 |
| AI 摘要/问答提示服务不可用 | Ark Key 或模型名不可用 | 检查 `application.yaml` 的 `app.ai.ark.*`；失败记录可在「AI 调用日志」查看 |
| AI 请求 15 秒就超时 | 前端曾用全局 15 秒超时 | 已改为 AI 专用 120 秒（`AI_REQUEST_TIMEOUT`），若仍超时请确认前端已重新构建 |
| 页面列表为空 / 图表全 0 | 未执行演示数据脚本 | 执行 `sql/00~10`、两个 seed 脚本与向量重建 |
| 中文数据插入报 `Incorrect string value` | mysql 客户端字符集非 utf8mb4 | 执行 SQL 时加 `--default-character-set=utf8mb4` |
| 管理端删除后统计未变 | 前端未刷新或用了旧实例 | 删除成功后会自动并行刷新文献库/看板；确认后端已重启为新版本 |
| 上传按钮转圈十几秒 | 上传时会同步重建索引并生成 AI 摘要（设计如此） | 按钮期间显示「正在建索引并生成摘要…」且禁用提交；AI 不可用时通常也在 10 秒内走兜底返回 |
