## 三、剩余改造计划（按批次）

### 第 2 批：删除教师端（B1）——本次新增的最大改动

| 项 | 内容 |
| --- | --- |
| 前端 | 删除 `views/worker/WorkerHomeView.vue`；移除 `/teacher/review` 路由与菜单项；登录页去掉教师角色选项；`auth.ts` 类型与角色映射去掉 TEACHER；`AppShell` 菜单去掉教师分组 |
| 后端 | `UserRole` 枚举调整（若保留兼容则只禁止登录）；登录接口拒绝 TEACHER；管理端用户列表的角色筛选去掉教师；演示数据里的 3 个教师账号改为学生或停用 |
| 数据 | `user_account` 中 3 个 TEACHER 账号处理：改为 STUDENT 或 status=0（需客户确认，建议停用保留历史外键） |
| 测试 | 集成测试里 9 处 TEACHER 相关断言需调整；新增「教师登录被拒绝」用例 |
| 风险 | 文献上传者里有教师账号（演示数据），删除角色后这些文献的归属需保留（关联 user_id 不删记录） |

### 第 2 批：管理端删除文献（A2）

- 管理中心审核队列/文献列表加「删除」按钮 + 二次确认（展示将被清理的分块/笔记/收藏数）
- 后端 `LiteratureService.delete` 补级联：逻辑删分块、删 Milvus 向量、清理收藏（已有物理删除方法可复用）、保留或清理笔记（待确认）
- 删除后刷新统计与列表

### 第 2 批：演示文献扩充（A1）

- 新增 10~12 篇，覆盖中英文、多分类、全部带原文与分块向量
- **重点**：为同一组文献准备「自然语言检索 / 语义检索 / 混合检索」的对比样例——同一 query 下三种模式召回结果要有可见差异（例如：自然语言检索走意图解析+关键词扩展；语义检索只看向量；混合检索靠 RRF 融合两路）
- 可复用 `scripts/verify-pdf-parsing.ps1` 的造数方式，产出 `sql/10_seed_demo_v2.sql` + `scripts/seed-demo-v2.ps1`

### 第 3 批：体验收尾

- 下载原文按钮：未绑定文件时置灰并提示
- 审核通过后自动重建索引 / 自动生成摘要（需客户确认）
- 论文截图清单（doc 06）按新 UI 重拍
