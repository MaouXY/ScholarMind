## 图 5 文献状态流转图

```mermaid
stateDiagram-v2
    [*] --> DRAFT : 上传/新建文献
    DRAFT --> PENDING_REVIEW : 提交公开审核
    PENDING_REVIEW --> PUBLISHED : 管理员通过
    PENDING_REVIEW --> REJECTED : 管理员退回（记录原因）
    REJECTED --> PENDING_REVIEW : 修改后重新提交
    PUBLISHED --> DRAFT : 撤回为草稿
    DRAFT --> [*] : 删除
    PUBLISHED --> [*] : 删除

    note right of DRAFT
        私有文献（visibility=PRIVATE）
        仅上传者可见，可直接在线阅读
    end note

    note right of PUBLISHED
        公开文献（visibility=PUBLIC）
        全体用户可检索、阅读、下载、引用
        索引状态：parse_status=INDEXED
        摘要状态：summary_status=SUCCESS/FALLBACK/FAILED
    end note
```

## 图 6 时序图

### 6.1 登录与鉴权

```mermaid
sequenceDiagram
    autonumber
    participant U as 浏览器（Vue）
    participant C as AuthController
    participant S as UserService
    participant J as JwtTokenService
    participant DB as MySQL

    U->>C: POST /api/v1/auth/login {username, password, role}
    C->>S: login(request)
    S->>DB: 查询 user_account（用户名 + deleted=0）
    DB-->>S: 用户记录（password_hash, role, status）
    S->>S: BCrypt 校验密码 + 校验账号状态与角色
    S->>J: 签发 JWT（principalId、roleCode、过期时间）
    J-->>S: token
    S-->>C: LoginResponse{token, expiresIn, user}
    C-->>U: ApiResponse{code=0, data}
    U->>U: 存入 localStorage

    Note over U,J: 后续请求携带 Authorization: Bearer token
    U->>C: GET /api/v1/...（带 token）
    C->>J: JwtAuthenticationFilter 解析 token
    J-->>C: CurrentUser 放入 SecurityContext
    C->>C: CurrentUserProvider.require() + 角色校验
```

### 6.2 混合检索（BM25 + 向量 + RRF）

```mermaid
sequenceDiagram
    autonumber
    participant U as 学生工作台
    participant C as LiteratureSearchController
    participant S as LiteratureAiService
    participant SP as SparseRetriever（BM25）
    participant MV as MilvusLiteratureVectorService
    participant RF as RrfFusion
    participant RK as RagRerankService
    participant DB as MySQL

    U->>C: POST /api/v1/search/hybrid {query, limit}
    C->>S: semanticSearch(request)
    S->>DB: 读取分块语料 + 文献元数据
    S->>S: 过滤：可读权限（私有文献仅上传者）+ 分类
    par 稀疏召回
        S->>SP: rank(query, corpus, topK=30, k1=1.2, b=0.75)
        SP-->>S: 候选 + BM25 得分 + 名次
    and 稠密召回
        S->>MV: search(query, topK)
        MV->>MV: 调用 Ark Embedding（2560 维）→ 余弦检索
        MV-->>S: 候选 + 相似度 + 名次
    end
    S->>RF: fuse(sparseRanked, denseRanked, k=60)
    RF-->>S: 融合结果（rrfScore + 两路名次）
    opt 开启重排
        S->>RK: rerank(query, fusedCandidates)
        RK-->>S: 最终排序
    end
    S->>DB: 写入 literature_search_log（查询、关键词、命中数）
    S-->>C: 引用分块（含 sparseRank/denseRank/rrfScore/retriever）
    C-->>U: 检索结果 + 融合解释信息
```

### 6.3 基于原文片段的 AI 问答（RAG）

```mermaid
sequenceDiagram
    autonumber
    participant U as 智能问答页
    participant C as LiteratureAiController
    participant S as LiteratureAiService
    participant M as Milvus / BM25
    participant A as AiClient（Ark）
    participant T as AiTaskService
    participant DB as MySQL

    U->>C: POST /api/v1/ai/literature/{id}/question {question, limit}
    C->>S: answer(literatureId, request)
    S->>DB: 校验文献可读（requireReadableLiterature）
    S->>M: 混合检索（BM25 + 向量 + RRF）取 TopN 引用片段
    M-->>S: 引用片段（chunkIndex + 内容）
    S->>T: createPending(LITERATURE_QUESTION, 请求快照)
    T-->>S: taskId（ai_task_record 落 PENDING）
    S->>A: generate(系统提示 + 文献题录 + 引用片段)
    alt 调用成功
        A-->>S: 答案文本
        S->>T: markSuccess(耗时、响应快照)
    else 调用失败
        A-->>S: 抛出异常
        S->>T: markFailed(错误信息)
        S-->>C: AI_SERVICE_UNAVAILABLE（前端提示且不阻塞阅读）
    end
    S->>DB: 写入 literature_qa_record（问题、答案、引用片段 JSON）
    S-->>C: 答案 + 引用片段
    C-->>U: 展示答案与可追溯引用
```

### 6.4 文献下载（RustFS 预签名）

```mermaid
sequenceDiagram

    participant C as LiteratureController

        S-->>C: {fileName, sizeBytes, url, expiresInSeconds, downloadCount}
        C-->>U: 返回下载票据
        U->>R: 浏览器直接访问预签名 URL
        R-->>U: 返回文件内容（不经应用服务器中转）
```

## 图 7 活动图：文献索引重建

```mermaid
flowchart TD
    START([开始重建索引]) --> AUTH{"当前用户对该文献可读？"}
    AUTH -- 否 --> DENY["14102 文献访问被拒"] --> END1([结束])
    AUTH -- 是 --> HASFILE{"文献已绑定原文文件？"}
    HASFILE -- 是 --> FETCH["从 RustFS 取回对象字节"]
    FETCH --> FETCHOK{"读取成功？"}
    FETCHOK -- 否 --> FALLBACK
    FETCHOK -- 是 --> EXTRACT["按类型解析正文<br/>PDF→PDFBox / docx→POI / txt→UTF-8"]
    EXTRACT --> ENOUGH{"正文长度 ≥ 200 字符？"}
    ENOUGH -- 是 --> USEFILE["使用正文作为索引语料<br/>parse_error=null"]
    ENOUGH -- 否 --> FALLBACK["回退：题录 + 摘要语料<br/>parse_error 记录原因"]
    HASFILE -- 否 --> FALLBACK
    USEFILE --> SPLIT
    FALLBACK --> SPLIT["按 chunkSize/overlap 切分"]
    SPLIT --> PERSIST["写入 literature_chunk（enabled=1）"]
    PERSIST --> VECTOR["写入 Milvus 分块向量"]
    VECTOR --> VOK{"写入成功？"}
    VOK -- 是 --> MARK["vector_store_status=MILVUS"]
    VOK -- 否 --> MARK2["vector_store_status=DB_ONLY<br/>检索退化为纯 BM25"]
    MARK --> DONE["parse_status=INDEXED"]
    MARK2 --> DONE
    DONE --> END2([返回 chunkCount 与解析状态])
```
